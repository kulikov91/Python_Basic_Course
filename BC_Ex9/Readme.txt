Задание 9. Итераторы и генераторы

Файлы:
    task9.py       - основное решение
    test_task9.py  - модульные тесты

В task9.py реализованы:

1. Класс Fibo
   Итератор возвращает последовательность:
   0, 1, 1, 2, 3, 5, 8, ...

   Реализованы методы:
   __init__
   __iter__
   __next__

   Для вычисления числа Фибоначчи используется сложение.

2. Генератор integers
   Возвращает:
   0, 1, 2, 3, 4, ...

3. Генератор primes
   Возвращает:
   2, 3, 5, 7, 11, 13, ...

Запуск программы:
    python task9.py

Запуск тестов:
    python -m unittest -v
